# Repli Registry

A curated registry of tested primitive skills and workflows.

## Why

Software has repositories for code.

We believe workflows deserve repositories too.

A workflow should be:

- Executable
- Testable
- Composable
- Reusable

## Structure

/primitives
/workflows
/tests

## Current Status

Version: v0

- All workflows covered by tests

## Contributing

We welcome:

- Primitive Skills
- Workflows
- Policy Fragments

Requirements:

- Must define input state
- Must define output state
- Must include tests
